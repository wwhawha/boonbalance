# BoonBalance PWA — เวอร์ชันแอปมือถือ
ใช้เวอร์ชันนี้แทนโฟลเดอร์เก่า ไม่ต้องรวมไฟล์สองเวอร์ชัน

## เปิดแก้ใน Visual Studio Code
1. แตก ZIP
2. File > Open Folder > เลือก boonbalance-pwa
3. ติดตั้ง Live Server แล้วคลิกขวา index.html > Open with Live Server
ไม่ต้องติดตั้ง npm

## อยากแก้อะไร เปิดไฟล์ไหน
- ข้อมูลชื่อสถานที่ คำอธิบาย ย่าน และรูป: data.js
- สี ระยะห่าง ขนาดตัวหนังสือ: style.css (ส่วนท้ายเป็นหน้าตาแอป)
- หน้า Welcome เมนู ปุ่ม และการทำงาน: app.js
- ชื่อแอปและไอคอนติดตั้ง: manifest.webmanifest และ assets/icon-*.png

## เปลี่ยนรูปเอง (ง่ายที่สุด)
นำรูป .jpg ใหม่มาแทนไฟล์ชื่อเดิมใน assets:

- khamchanot.jpg — วัดป่าคำชะโนด
- hiran.jpg — ศาลท้าวหิรัญพนาสูร
- kuanyin.jpg — มูลนิธิเทียนฟ้า
- tiger.jpg — ศาลเจ้าพ่อเสือ
- watkhaek.jpg — วัดแขก
ใช้ภาพแนวนอนประมาณ 1200 × 800 พิกเซล ถ้ามีไฟล์ชื่อเดิมให้ Replace

ถ้าต้องการใช้ .png ให้เปลี่ยนการอ้างอิงใน app.js จาก assets/${p.img}.jpg เป็นนามสกุลที่ใช้จริง หรือปรับให้ข้อมูลเก็บชื่อไฟล์พร้อมนามสกุล

## แชร์ผ่าน GitHub Pages
สร้าง repository Public ชื่อ boonbalance แล้วอัปโหลดไฟล์ **ข้างใน** โฟลเดอร์ boonbalance-pwa ทั้งหมด ให้ index.html อยู่ชั้นแรก พร้อมโฟลเดอร์ assets

## ติดตั้งลงมือถือ
เปิด URL HTTPS ที่เผยแพร่แล้ว
- iPhone/iPad: เปิด Safari > แชร์ > เพิ่มไปยังหน้าจอโฮม > เปิดเป็นเว็บแอป (ถ้ามี) > เพิ่ม
- Android/Chrome: เมนู ⋮ > ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก (ขึ้นกับอุปกรณ์)
มีหน้าคำแนะนำในแอปผ่านปุ่ม + ติดตั้งแอป
เมื่อเปิดจากไอคอนจะใช้ standalone บนอุปกรณ์ที่รองรับ
การเปิดไฟล์โดยตรงแบบ file:// ใช้ทดลองหน้าตาได้ แต่ลงทะเบียน service worker ไม่ได้ ต้องใช้ localhost หรือ HTTPS

## ออฟไลน์และการอัปเดต
Service worker เก็บไฟล์แอปและภาพในเครื่องหลังโหลดครั้งแรก แผนที่ภายนอกยังต้องใช้อินเทอร์เน็ต
หลังแก้โค้ด/รูป ให้เปลี่ยนเลข boonbalance-v2 ใน sw.js เป็น v3, v4 ตามครั้งที่เผยแพร่ เพื่อให้เกิดการติดตั้ง cache รุ่นใหม่
แอปใช้ network-first เมื่อออนไลน์ และ fallback เป็น cache เมื่อออฟไลน์
หลังอัปเดตให้ปิดแอปทุกหน้าต่างแล้วเปิดใหม่ ถ้ายังเห็นภาพเดิมให้รีโหลด
ถ้าเพิ่มรูปใหม่ ต้องเพิ่ม path ใน FILES ของ sw.js เพื่อให้พร้อมใช้ออฟไลน์

## ขอบเขต
เป็น PWA ต้นแบบ ไม่ใช่ไฟล์ APK หรือแอปใน App Store
โปรไฟล์ทดลองใช้ชื่อเล่น ไม่ใช่ระบบบัญชีผู้ใช้จริง
รายการโปรดและเช็กลิสต์เก็บใน localStorage เฉพาะเครื่อง ไม่ได้แชร์ข้ามอุปกรณ์
ไม่มี backend, OAuth, รีวิวจริง หรือระบบผู้ให้บริการ/ผู้ดูแล
ข้อมูลเวลาเปิด–ปิดและข้อปฏิบัติที่ยังไม่ยืนยันจะแสดงให้ตรวจสอบกับสถานที่
ไม่มีการรับรองผลการขอพร รูปจากวิดีโอใช้ประกอบต้นแบบตามไฟล์ที่ผู้ใช้ให้

## ตรวจสอบแล้ว
ตรวจ syntax JavaScript, เส้นทางทั้ง 4 หมวด, หน้ารายละเอียด/ลิงก์แผนที่, ค้นหาไม่พบข้อมูล, บันทึกสถานที่, เช็กลิสต์ และรายการโปรดด้วย DOM จำลอง
ตรวจ manifest, ขนาดไอคอน, ขอบเขต cache และรายการไฟล์ออฟไลน์
ยังไม่ได้ทดสอบติดตั้งจริงบน iPhone/Android หรือทดสอบหน้าตาใน browser จริง เพราะ environment นี้ไม่มี browser binary ที่ใช้งานได้
